# Art direction and engine guide

The demo's look: **Brawl Stars-style stylized 3D**. Chunky, toy-like characters with big heads and hands, saturated colors, soft cel shading with a rim light, thin dark outlines, crisp cartoon faces, snappy exaggerated animation. Everything is generated by code: no image or model files.

## Style rules

- **Proportions**: heads 35–45% of body height, big hands and feet, short legs, simple readable silhouettes. Creatures follow the same chunky, cute-but-cool language.
- **Shapes**: sculpt with smooth unions (`S.union(k, ...)`) so parts melt together like clay, but keep distinct features readable. Blend radius `k` about 0.02–0.06 for bodies, smaller (0.01–0.03) for hair clumps and details. Avoid blobby mush: every part should have a clear shape.
- **Detail**: add secondary shapes that sell the design (seams, bands, pockets, horns, spikes, plates, rivets, claws) with 2–3 tones per material, not flat single colors.
- **Color**: saturated, clean. Each character or creature has one dominant color, one accent, one neutral. Essence creatures use their essence color (see `prototypes/skill-forge/data-essences.js`: `color`, `glow`). Emissive parts (glowing eyes, runes, crystals, fire) use `P(color, gloss, 1.0)` and bloom.
- **Gloss** (`P(color, gloss)`): cloth 0.08–0.15, skin 0.2–0.25, hair 0.2, leather 0.25, plastic/shell 0.4–0.6, metal/gems 0.8–0.95.
- **Faces**: never sculpt eyes or mouths. Use face decals (`buildFace`, see below): outlined eyes with highlights, brows, mouth. Creatures can use `eye`/`mouth` decals too (glowing eyes: pass `iris` bright + later set `uGlow`).
- **Scale**: 1 unit = 1 meter. Heroes are about 1.5 m tall including hair. Minions 0.5–0.9 m, titans 2.5–4 m, critters 0.3–0.5 m. Characters face +Z; their left side is +X.
- **Budget**: after meshing, heroes about 20–30k vertices at `cell` 0.014, minions and critters under 8k (cell 0.016–0.02), titans under 30k (cell scaled to size, e.g. 0.035). Check `stats` printed by the lab.

## Engine API (src/engine)

- `sdf.js` — `S.sphere(c, r)`, `S.ellipsoid(c, [rx,ry,rz])`, `S.box(c, [hx,hy,hz], round)`, `S.taper(c, half, taper, round)`, `S.limb(a, b, r1, r2)` (tapered capsule, great for limbs, horns, tails, spikes), `S.torus(c, R, r)`, `S.cyl(c, r, halfHeight, round)`; `.rot(rx, ry, rz)` on primitives; ops `S.union(k, ...)`, `S.sub(k, base, ...cutters)`, `S.carve(k, base, ...cutters)` (cut surface takes the cutter's paint), `S.inter(k, ...)`; deformers `S.mirror(node)` (mirror across X: author the +X side, bone names ending `.L` auto-swap to `.R`), `S.twist`, `S.bend`, `S.displace(node, amp, freq)` (rocks, bark), `S.round`, `S.shell`. Metadata on any node: `.paint(p)` (fills unpainted leaves), `.over(p)` (forces), `.bone(name)`, `.group(name)` (skin weights only blend within a group: use for cloth, hair, tails), `.rigid()` (100% one bone), `.weight(w)`.
- Paints: `P('#hex', gloss, emissive)`; functions `(x,y,z,leaf,nx,ny,nz,cell) => ({color:[r,g,b], gloss, emissive})` for gradients, stripes, spots. Helpers in `src/art/kit.js`: `gradientPaint`, `hairPaint`, `skinPaint` (cheek blush), `bandPaint` (stripes by height), `mottled`.
- `src/art/kit.js` parts: `humanoid(proportions)` (skeleton spec + joints), `hand(wrist, side, size, paint, bone)`, `sneaker(ankle, side, colors, bone)`, `hairClump(root, tip, r1, r2, bend)`.
- `rig.js` — `buildSkeleton(spec)` (spec = ordered `{ name: { parent, pos:[x,y,z] } }`, absolute rest positions), `skinnedModel(sdf, rig, { mesh: { cell, aoStep, tau }, outlineOpts: { width } })`, `staticModel(sdf, { mesh: { cell } })` for rigid things.
- `face.js` — `buildFace(projectionSdf, headBone, headRestPos, features)`; features: `{ kind: 'eye'|'brow'|'mouth', name, side, center, dir, size:[w,h], ...colors/shape }`. Project onto a head-only SDF so hair doesn't catch the decal.
- `anim.js` — `Animator(rig, face)`: humanoid procedural animation. Set `anim.s.speed`, `anim.s.action = { kind, t, dur, side }` (kinds: punch, cast, throw, slam, dash, hit, summon), `stunned`, `victory`, `dead`, `airborne`, `aimLocal`, `mood`, `moveVel`; call `anim.update(dt)`.
- `toon.js` — `toonMaterial(opts)`, `outlineMaterial`, `blobShadow(radius, opacity)`.

## Visual QA

Every asset gets checked in renders before it's done:

```sh
node tools/shoot.cjs "lab.html?scene=hero&id=kai" shots/x.png --w 640 --h 800 --frames 4 --dt 1 --cols 4 --scale 0.6   # turnaround
node tools/shoot.cjs "lab.html?scene=anim&seq=run" shots/y.png --w 420 --h 520 --warm 0.2 --frames 8 --dt 0.08 --cols 8 --scale 0.5
python3 tools/stack.py out.png a.png b.png    # stack sheets (-h for horizontal)
```

Lab scenes live in `src/lab/<name>.js` and export `setup(stage, params)` returning `{ update(dt), info() }`. Then view PNGs with the image reader and iterate until they look like a shipped mobile game, not a prototype.
